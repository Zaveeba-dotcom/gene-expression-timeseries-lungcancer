# Gene Expression Time-Series Analysis in Lung Cancer

Analysis of gene expression dynamics across 20 time points in lung cancer samples from a public GEO dataset, tracking four genes of interest — **HOPX, SPARCL1, TFF1, APOB**.

## What this does
- Loads a gene expression matrix and sample metadata (GEO accessions, phenotype, time point)
- Filters to cancer-phenotype samples
- Reshapes the data into long format for plotting
- Produces a time-series **area graph** showing expression trends for the four genes across the full time course

## Files
- `area_graph_analysis.R` — analysis and plotting script
- `gene_expressions.csv` — expression matrix (genes as rows, sample accessions as columns)
- `metadata.csv` — sample metadata (GEO sample accessions, phenotype, time point)
- `Genes.txt` — the four genes plotted (HOPX, SPARCL1, TFF1, APOB)
- `TimeSeries_Area_Graphs.pdf` — output plot generated by the script
